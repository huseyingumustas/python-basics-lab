# Python Basics Lab

Welcome to my Python learning journey. This repository contains basic Python projects and algorithms developed to master core programming logic.

## Projects

### 1. Number Guessing Game
A game where the computer picks a random number between 1 and 100, and the player tries to guess it.
* **Concepts:** Random library, while loops, if/else logic.
* **File:** `number_guessing_game.py`

### 2. Hangman
A classic word-guessing game with a list of fruits. Includes duplicate letter check and input validation.
* **Concepts:** Lists, for loops, membership operators (`in`), input handling.
* **File:** `hangman.py`
